My IB Personal Project: Making a Website as a Beginner

My Coding Journey

By: Ibrahim Abdullah Alzuhair

Learning Goal

My learning goal is to learn the coding skills required to make a website from scratch, which requires HTML, CSS, and JavaScript knowledge.

Product Goal

To program a fully functional website that seeks to teach people with no prior experience the basics of web development, why they should consider it, and how to get started.

Why should I consider coding?

Coding isn't just typing lines of code, it's the language of the internet and a key skill in today's tech-driven world. It lets you bring ideas to life without being limited by apps or websites. The rules of coding often boost creativity, pushing you to find clever solutions to problems. Even if you don't become a full-time programmer, knowing the basics gives you an edge in any field and shifts the way you think.

How can I start coding?

The good part about coding is that anyone can learn it, anywhere, any time. You can start online via YouTube tutorials, free online courses, or interactive websites. People have different learning styles, so you can experiment as much as you like until you find what clicks with you. To start, there is a section below dedicated to tutorials.

Web Development Basics

Learn the three core technologies that power the web

HTML

HTML (HyperText Markup Language) is the backbone of any website. It defines the structure and content of web pages using a system of tags and attributes. Think of HTML as the skeleton that gives a website its basic form; it creates headings, paragraphs, links, images, and more.

With HTML, you can create static web pages that display information in an organized way. It's the first language you should learn when starting web development.

Learn HTML at W3Schools

CSS

CSS (Cascading Style Sheets) is what makes websites visually appealing. It controls the presentation, formatting, and layout of HTML elements. With CSS, you can add colors, change fonts, create beautiful layouts, and even add animations.

CSS transforms the plain structure of HTML into a visually engaging experience, making it essential for creating modern, responsive websites that look good on all devices.

Learn CSS at W3Schools

JavaScript

JavaScript brings websites to life by adding interactivity and dynamic behavior. It allows websites to respond to user actions, update content in real-time, validate forms, create animations, and much more without requiring page reloads.

As the only programming language that runs natively in web browsers, JavaScript is crucial for creating modern web applications that feel responsive and app-like.

Learn JavaScript at W3Schools

My Journey's Milestones

November 11, 2024

Challenge: I didn't know where to begin or what to focus on first in Python. Everything felt new.

Solution: I picked one topic (Python basics) and followed the order of the W3Schools lessons.

Lesson for readers: Don't overthink the starting point—just start. Use free resources and stay consistent.

December 4, 2024

Challenge: I couldn't understand how HTML, CSS, and JS worked together.

Solution: I made small experiments to test changes.

Lesson for readers: Try changing one thing at a time. It helps you see what each part does clearly.

January 9, 2025

Challenge: I kept looking at other people's code instead of writing my own.

Solution: I forced myself to build something from a blank file, even if it looked bad.

Lesson for readers: You learn more by doing it yourself. Copying won't help unless you learn something from it and can replicate it.

February 15, 2025

Challenge: My layouts were always broken or uneven when using CSS.

Solution: I practiced making page layouts aiming for aesthetics and symmetry.

Lesson for readers: Don't undermine layouts and aesthetics, they can make the finished product feel a lot more rewarding and motivate you to continue further.

March 27, 2025

Challenge: I didn't understand how to make elements respond to clicks or user input with JavaScript.

Solution: I started with basic functions like onclick and built small interactive parts step by step.

Lesson for readers: Add interactivity in small steps, don't try to build complex features too soon.
